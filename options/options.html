使い方

基本的な流れ

  1. フォームを開き、手で必要項目を入力する
  2. 右下の「入力内容を学習」ボタンを押すと、入力した項目が一覧で表示される
  3. 保存したい項目と使う範囲を選んで「保存」— 次回から自動入力できる

ルールの書き方

  • "name1" — ダブルクォート囲み = 正規化した name / id に完全一致
  • name1 — 裸文字列 = 同じく完全一致
  • /^kname\d$/i — スラッシュ囲み = name / id に対する正規表現

サイト指定

  • サイト欄が空 = 全サイトに適用
  • example.com — そのホストとサブドメインで動作
  • https://example.com/form/ — その URL プレフィックスでのみ動作
種別 ラベル name 値 サイト（空欄 = 全サイト）
