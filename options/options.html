0件のルール
保存済み
💡 使い方

基本的な流れ

  1. 就活サイトなどのフォームを開き、手で必要項目を入力する
  2. 右下の「📝 入力内容を学習」ボタンを押すと、今入力した項目が全部ルール候補として出てくる
  3. 保存したい項目と使う範囲を選んで「保存」→ 次回から自動入力できる

ルールの書き方

  • "name1" - ダブルクォート囲み = 正規化した name / id に完全一致
  • name1 - 裸文字列 = 同じく完全一致
  • /^kname\d$/i - スラッシュ囲み = name / id に対する正規表現

サイト指定

  • サイト欄が空 = 全サイトに適用
  • example.com はそのホストとサブドメインで動作
  • https://example.com/form/ はその URL プレフィックスでのみ動作

サイト欄を空欄にするとルールは全サイトに適用されます。特定ページだけに限定したい場合は example.com または https://example.com/form/ を指定してください。

種別 ラベル(メモ) name 値 サイト(空欄=全サイトに適用)
