AutoFill JP プライバシーポリシー

本ポリシーは、AutoFill JP がどのデータを処理し、どこに保存し、何に使わないかを説明するものです。 最終更新日は 2026-04-23 です。

製品概要へ戻る Limited Use を読む

Summary

  • ルール本体はブラウザ内の chrome.storage.local に保存します。
  • password / hidden フィールドは学習も自動入力もしません。
  • 入力データを外部サーバーへ送信しません。
  • 広告、データ販売、第三者提供、トラッキング目的の利用は行いません。

1. 取得・処理する情報

ユーザーが明示的に入力したフォーム情報

AutoFill JP は、ユーザーが対象ページで入力した通常フィールドの値と、その値に対応するフィールド識別子を処理します。

  • 例: 氏名、住所、電話番号、学校名、メールアドレスなど、ユーザーが自分で入力した値
  • フィールド識別子: name、id、ルールのサイト指定、ラベルメモ
  • 軽微な設定: フローティングボタン表示設定など

2. 取り扱わない情報

保存も入力もしないもの

  • パスワード欄 (type="password")
  • hidden フィールド (type="hidden")
  • ページ本文全体、閲覧履歴、広告識別子、分析用イベント
  • 第三者サービスへ送るための利用ログやトラッキングデータ

3. 保存場所と保持

ブラウザ内保存が基本です

  • 学習ルール本体は chrome.storage.local に保存します。
  • 軽微な設定は chrome.storage.sync を使う場合があります。
  • ユーザーは拡張機能の設定画面からルールの編集・削除・エクスポート・インポートを行えます。
  • 拡張機能側で保存期間を自動延長したり、外部バックアップへ複製したりすることはありません。

4. 利用目的

単一目的のためだけに使います

処理したデータは、ユーザーが訪れたフォームに対して自動入力を行うためだけに使います。

  • 広告表示、広告測定、ユーザープロファイリングには使いません。
  • データ販売や第三者提供には使いません。
  • AI 学習、データブローカー、外部分析基盤への転用はしません。

Chrome Web Store Limited Use

Limited Use 開示

AutoFill JP は、Chrome Web Store Developer Program Policies の Limited Use 要件に従い、 ユーザーデータをユーザーが明示的に要求した自動入力機能の提供にのみ使用します。

  • 取得したデータを第三者へ販売しません。
  • 広告配信、クレジット評価、データブローカー、人物属性推定に利用しません。
  • 人の閲覧を伴うのは、法令遵守、セキュリティ、サポート対応など限定的な場合に限ります。現行版では外部送信自体を行いません。
  • ユーザーがフォーム上で明示的に利用した範囲を超えてデータを転用しません。

5. 送信・共有

外部送信しません

現行バージョンの AutoFill JP は、学習ルールや入力データを開発者サーバー、解析基盤、広告サービス、第三者 API へ送信しません。

6. 問い合わせ

サポート窓口

サポート窓口は 製品概要ページの Support セクション に掲載します。公開前に実運用の連絡先へ差し替えてください。
