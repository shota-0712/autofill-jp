保存するもの

あなたがフォームに入力した内容

名前・住所・電話番号・学校名など、フォームに自分で入力した値を学習します。データはすべてあなたのChromeブラウザの中にだけ保存されます。

  • 名前・住所・電話番号・メールアドレスなど
  • どのフィールドに対応するかの識別情報
  • フローティングボタンの表示設定など軽微な設定

保存しないもの

パスワードと隠しフィールドは対象外です

機密性の高い情報は最初から学習の対象外にしています。

  • パスワード欄の入力内容
  • 画面に表示されない隠しフィールド
  • 閲覧履歴・広告識別子・行動トラッキングデータ
  • 広告や分析サービスに送るためのデータ

どこに保存されるか

あなたのChromeブラウザの中だけです。

入力データは外部のサーバーやクラウドには送られません。すべてあなたのパソコンのChrome内に保存されます。

  • 開発者も含め、第三者はあなたのデータにアクセスできません。
  • 設定画面からいつでもルールを確認・編集・削除できます。
  • 拡張機能をアンインストールすれば、保存データもすべて消えます。

何に使うか

フォームへの自動入力だけに使います。

学習した入力情報は、次回のフォーム自動入力のためだけに使います。それ以外の目的には一切使いません。

  • 広告の表示・計測には使いません。
  • データを販売したり、第三者に提供したりしません。
  • AIの学習や外部の分析サービスへの転用もしません。

Chrome Web Store Limited Use

Limited Use 開示

AutoFill JP は、Chrome ウェブストアのポリシー（Limited Use 要件）に従い、ユーザーのデータをフォーム自動入力機能の提供にのみ使用します。

  • 取得したデータを第三者へ販売しません。
  • 広告配信・クレジット評価・データ分析に利用しません。
  • 外部への送信は一切行いません。データはChrome内にだけ保存されます。
  • ユーザーがフォームで入力した範囲を超えてデータを利用しません。

外部への送信

データは外に出ません。

AutoFill JP は、学習した入力内容を開発者のサーバーや広告サービス、分析ツールなど外部のどこにも送信しません。インターネット通信は一切発生しません。
