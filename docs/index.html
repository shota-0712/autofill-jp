Chrome Extension

手入力した内容を、次のフォームでも使い回せるようにする。

名前・住所・学校名など、フォームで毎回入力する情報を一度学習させるだけ。次からは自動で入力されます。

プライバシーポリシー サポート
Chrome内にだけ保存データが外に出ることはありません
パスワードは保存しないパスワード欄は対象外です
どのフォームでも使える就活・申込・登録など幅広く対応
広告・データ販売なし入力情報を第三者に渡しません

使い方

3ステップで完了します。

1

フォームに入力する

いつも通りフォームを入力します。ページ右下にボタンが表示されます。

2

「入力内容を学習」で保存する

保存したい項目を選んで保存するだけ。次回から使い回せます。

3

次回は「自動入力」で完了

「自動入力を実行」を押すと、前回の入力内容がまとめて入力されます。

データについて

入力した内容はChromeの中だけに保存されます。

  • 保存先はあなたのブラウザの中だけです。外部のサーバーには一切送りません。
  • パスワードや非表示フィールドは学習の対象外です。
  • 設定画面からいつでもルールを確認・編集・削除できます。
  • アンインストールすれば保存データもすべて消えます。

主な機能

サイトをまたいで使い回せます。

  • 学習したルールはどのサイトでも使えます。就活サイト・各種申込フォームなど、サイトごとに設定し直す必要はありません。
  • サイトを指定して「このサイトだけ」に絞ることもできます。
  • 設定画面でルールの追加・編集・削除が自由にできます。
  • エクスポート・インポートで別のPCに設定を移せます。

広告・トラッキングなし

入力情報は自動入力にしか使いません。

  • 広告の表示や計測には使いません。
  • データを企業や第三者に販売しません。
  • 分析サービスや外部APIへの送信は行いません。
  • あなたの入力内容はあなたのChrome内だけに留まります。
