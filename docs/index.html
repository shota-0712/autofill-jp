Chrome Extension / Japan Job Forms

手入力した内容を、次のフォームでも使い回せるようにする。

AutoFill JP は、日本の就活・適性検査・各種エントリーフォーム向けの学習型自動入力拡張です。 ユーザーがページ上で入力した値をローカルに保存し、次回は対応するフィールドへまとめて自動入力します。

Privacy / Limited Use Support

What It Does

  • フォームに入力済みの通常フィールドをまとめて学習し、次回の入力を短縮します。
  • ルールは { name, value, site } を基本としてブラウザ内に保存します。
  • サイト欄が空欄のルールは全サイトに適用され、必要に応じてホストまたは URL プレフィックスで絞り込めます。
  • 対象はトップフレームの http(s) ページで、パスワード欄と hidden フィールドは扱いません。

Single Purpose

目的は、ユーザーが自分で入力したフォーム情報の再利用だけです。

AutoFill JP は、就活サイトや応募フォームで繰り返し入力する氏名、住所、学校名、電話番号などの再入力を減らすために設計されています。 収集したデータを広告、分析、トラッキング、販売、第三者提供に使うことはありません。

Local First No Remote Code No Password / Hidden Fields Top-Frame UI Only

主な仕様

公開版の挙動

  • Rule.name は、裸文字列と引用付き文字列では正規化した name / id の完全一致です。
  • 広い一致は /regex/flags のみ許可しています。
  • Rule.site が空欄なら全サイト、非空ならホスト一致または URL プレフィックス一致で評価します。
  • 既に意味のある値が入っている通常フィールドは原則として上書きしません。
  • FAB、トースト、学習モーダルはトップフレームのみに表示します。

Permissions

必要な権限

storage

学習ルールと設定をブラウザ内に保存するために使います。

contextMenus

ページ上の右クリックメニューから自動入力と学習を呼び出すために使います。

All Sites Access

就活サイトごとに DOM 構造が異なるため、ユーザーが訪れた任意の http(s) フォームで同じ機能を提供するために必要です。

Data Handling

取り扱うデータ

  • 学習対象は、ユーザーがページ上で入力した通常フィールドの値と、対応するフィールド識別子です。
  • ルール本体は chrome.storage.local に保存されます。
  • 軽微な UI 設定のみ chrome.storage.sync を使う場合があります。
  • 入力内容を外部サーバーへ送信したり、第三者へ共有したりする処理はありません。
