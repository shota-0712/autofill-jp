Chrome Extension

手入力した内容を、次のフォームでも使い回せるようにする。

名前・住所・学校名など、フォームで毎回入力する情報を一度学習させるだけ。次からは自動で入力されます。

使い方

3ステップで完了します。

難しい設定は不要です。フォームに入力したあと「学習」するだけで、次回から自動で入力されます。

① フォームに入力する ② 右クリック →「このページの入力内容を学習」 ③ 次回は「自動入力を実行」で一括入力

データについて

入力した内容はChromeの中だけに保存されます。

  • 保存先はあなたのブラウザの中だけです。外部のサーバーには一切送りません。
  • パスワードや非表示フィールドは学習の対象外です。
  • 設定画面からいつでもルールを確認・編集・削除できます。
  • アンインストールすれば保存データもすべて消えます。

権限について

なぜこの権限が必要なのか。

ストレージ

学習した入力ルールをブラウザ内に保存するために使います。

右クリックメニュー

「自動入力を実行」「入力内容を学習」を右クリックから呼び出すために使います。

すべてのサイトへのアクセス

就活サイトや申込フォームはサイトごとに構造が異なるため、どのサイトでも同じように使えるようにするために必要です。

広告・トラッキングなし

入力情報は自動入力にしか使いません。

  • 広告の表示や計測には使いません。
  • データを企業や第三者に販売しません。
  • 分析サービスや外部APIへの送信は行いません。
  • あなたの入力内容はあなたのChrome内だけに留まります。
