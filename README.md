# AutoFill JP

日本の就活・適性検査・各種フォーム向けの、学習型自動入力 Chrome 拡張機能。

## 特徴

- **学習型**: フォームに手入力した内容から一括でルールを自動生成
- **シンプル**: Rule は `{ name, value, site }` を基本に、必要な補助情報だけを追加
- **適性検査対応**: `value` が同じラジオボタン群でも、選択肢の位置を補助情報として保存して再現
- **範囲選択**: 学習時に「このサイトだけ」「このURL配下」「全サイト」を選択可能
- **日本語UI**: 全て日本語で完結
- **安定保存**: ルール本体は `chrome.storage.local` に保存し、`sync` の容量制限を回避
- **安全**: password / hidden フィールドは学習も自動入力もしない
- **公開向け**: `http(s)` のトップフレームにだけ UI を出す

## インストール方法

1. このフォルダをどこかに展開
2. Chrome で `chrome://extensions/` を開く
3. 右上の「デベロッパーモード」をオン
4. 「パッケージ化されていない拡張機能を読み込む」からこのフォルダを選択

インストール直後に設定画面が1回だけ自動で開きます。

## 使い方

### 基本フロー

1. 就活サイトなどのフォームを開き、手で必要項目を入力する
2. ページ右下の **「📝 入力内容を学習」** ボタンを押す
3. 検出されたフィールド一覧から保存したい項目と、ルールを使う範囲を選んで保存する
4. 次回同じ形式のフォームを開いたら **「🪄 自動入力」** で一括入力する

適性検査のような横並びのラジオ回答欄では、同じ `name` の選択肢のうち何番目を選んだかも保存します。選択肢の `value` がすべて `on` のように同じ場合でも、同じ画面構造なら過去の回答位置を再現できます。

自動入力時は、既に入力されている欄や選択済みの回答グループは上書きしません。備考・コメント・自由記述のような汎用欄では、保存時のラベルと現在の欄ラベルが合わない場合は入力を見送ります。

### 右クリックメニュー

ページ上で右クリックして以下を選べます。

- 🪄 自動入力を実行
- 📝 このページの入力内容を学習
- ⚙️ 設定を開く

### ルールの書き方

設定画面で手動編集する場合、**name 列**は `name` / `id` に対して次の3通りで評価されます。

| 書式 | 意味 | 例 |
|---|---|---|
| `"name1"` | 正規化した `name` / `id` に完全一致 | `"kname1"` |
| `name1` | 同上 (裸文字列) | `kname1` |
| `/regex/flags` | `name` / `id` に対する正規表現 | `/^kname\d$/i` |

### サイト指定

- **空欄 = 全サイトで動作**
- `example.com` はそのホストとサブドメインで動作
- `https://example.com/form/` はその URL プレフィックスでのみ動作
- `String.includes()` ベースの曖昧一致は行わない

## ファイル構成

```text
autofill-jp/
├── manifest.json
├── popup/          ツールバーアイコンのポップアップ
├── options/        ルール管理画面
├── content/        ページに注入される処理(学習・自動入力・モーダル)
├── background/     Service Worker(右クリックメニュー等)
├── docs/           GitHub Pages 用の公開ページ/ストア文面
└── icons/
```

## セキュリティ

- ルール本体は `chrome.storage.local` に保存
- 軽い設定値は `chrome.storage.sync` に保存
- 外部サーバーには一切データを送信しない
- パスワード欄 (`type="password"`) と hidden フィールドは保存も自動入力もしない
- 既に値が入っているテキスト欄は上書きしない
- ページ内 UI はトップフレームにのみ表示する
